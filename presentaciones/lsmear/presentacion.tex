\begin{frame}{El branching decide el costo del B\&B}
\small
\begin{block}{Contexto}
La optimización global continua se resuelve deterministamente con \textit{interval branch and bound}.
\end{block}

\begin{itemize}
  \item Cada nodo se bisecciona en dos subproblemas.
  \item La variable elegida condiciona el tamaño del árbol.
  \item Se busca una solución $\epsilon$-óptima sin explorar demasiados nodos.
\end{itemize}

\begin{alertblock}{Limitación}
Las estrategias clásicas usan información local del nodo, pero ignoran qué restricciones importan más.
\end{alertblock}
\end{frame}

\begin{frame}{Las heurísticas clásicas pesan todo por igual}
\small
\begin{columns}[T]
\column{0.48\textwidth}
\textbf{Reglas de referencia}
\begin{itemize}
  \item \texttt{round-robin}: rota variables sin usar información local.
  \item \texttt{largest-first}: elige el mayor dominio.
  \item \texttt{smear}: estima impacto con derivadas intervalares.
\end{itemize}

\column{0.48\textwidth}
\textbf{Dónde fallan}
\begin{block}{Idea}
Si una restricción está activa, su efecto guía el branching; si está inactiva, aporta poco.
\end{block}

\[
\operatorname{smear}(x_i,g_j)=\operatorname{wid}(x_i)\,|a_{ji}|
\]
Mide ancho por sensibilidad local.

\[
\operatorname{smearsum}(x_i)=\sum_{j=1}^m \operatorname{smear}(x_i,g_j)
\]
Suma el efecto de todas las restricciones por igual.
\end{columns}

\begin{alertblock}{Mensaje clave}
El agregado puede ser engañoso: restricciones inactivas pueden dominar la elección.
\end{alertblock}
\end{frame}

\begin{frame}{La idea: usar multiplicadores de Lagrange óptimos}
\small
\begin{block}{Definición}
Se linealiza el problema alrededor del centro de la caja actual y se resuelve esa aproximación.
\end{block}

\begin{exampleblock}{Idea}
Los multiplicadores duales óptimos reponderan cada restricción antes de calcular el smear.
\end{exampleblock}

\begin{block}{Selección}
Se evalúa un Lagrangiano ponderado y se biseca la variable con mayor impacto.
\end{block}

\begin{alertblock}{Mensaje clave}
\alert{No todas las restricciones pesan igual}: la estrategia aprende su relevancia de la linealización.
\end{alertblock}
\end{frame}

\begin{frame}{El Lagrangiano explica qué restricciones importan}
\begin{block}{Definición}
\[
L(x,\lambda)=f(x)+\sum_{j=1}^{m}\lambda_j\,g_j(x), \qquad \lambda_j\ge 0
\]
\end{block}

\small
\begin{itemize}
  \item $f(x)$ es la función objetivo; la suma penaliza violaciones de restricción.
  \item Cada $\lambda_j$ pondera la restricción $g_j(x)\le 0$ asociada.
  \item $\lambda^\star$ son los \textbf{multiplicadores duales óptimos} del problema.
  \item \alert{$\lambda_j^\star$ mide la sensibilidad óptima frente a la restricción $j$.}
  \item Si una restricción es inactiva, su multiplicador óptimo es $0$.
\end{itemize}
\end{frame}

\begin{frame}{\texttt{lsmear} combina linealización y smear}
\small
\begin{columns}[T,onlytextwidth]
\begin{column}{0.58\textwidth}
\begin{algorithm}[H]
\scriptsize
\KwIn{caja $\mathbf{x}$, Jacobiano intervalar $J$, restricciones $g$}
\KwOut{variable a bisecar}
linealizar $g$ en $\operatorname{mid}(\mathbf{x})$\;
resolver el LP con cotas de $\mathbf{x}$ y objetivo no acotado\;
\If{el LP es infactible o no acotado}{
\Return \texttt{smearsum}$(\mathbf{x},J)$\;
}
\For{$i=1,\dots,n$}{
  $D \gets \lambda_i^\star$\;
  \For{$j=1,\dots,m$}{
    $D \gets D + \lambda_{n+j}^\star \, J_{ji}$\;
  }
  medir $|\;D\cdot \operatorname{wid}(x_i)\;|$\;
}
\Return $\argmax_i |\;D\cdot \operatorname{wid}(x_i)\;|$\;
\end{algorithm}
\end{column}
\begin{column}{0.42\textwidth}
\begin{block}{Idea central}
La \alert{ponderación por multiplicadores duales óptimos} aproxima la importancia real de cada restricción.
\end{block}
\begin{exampleblock}{Implementación}
\texttt{IbexOpt} integra \texttt{lsmear}; el LP se resuelve con \texttt{SoPlex}.
\end{exampleblock}
\begin{alertblock}{Fallback}
Si falla la fase lineal, la estrategia usa \texttt{smearsum} con el mismo $J$.
\end{alertblock}
\end{column}
\end{columns}
\end{frame}

\begin{frame}{La conclusión es un branching más informado}
\begin{block}{Idea principal}
\texttt{lsmear} pondera restricciones con multiplicadores duales óptimos y define un smear lagrangiano.
\end{block}

\begin{exampleblock}{Mejor variante}
\texttt{lsmear-MG} ofrece el mejor compromiso entre rendimiento y simplicidad.
\end{exampleblock}

\begin{block}{Ventaja estructural}
Es independiente del contractor convexo usado por el solver.
\end{block}
